# Як писати уроки «Зошита» (схема v2, 1–11 класи)

Кожен урок — окремий файл `data/gXX/lessons/<subject>/<id>.json`, де `gXX` — клас (`g01` … `g11`), а `id`
береться з `data/gXX/plan.json` (наприклад `math-w03-d1`). Файл — валідний JSON (UTF-8, без коментарів).

Перевірка (обов'язково після кожного файлу, до 0 помилок):

```
python3 tools/validate.py g07 data/g07/lessons/alg/alg-w03-d1.json
python3 tools/validate.py g07 --net data/g07/lessons/istu/*.json     # якщо є зображення: перевіряє, що вони відкриваються
```

Мова уроків — українська (в англійській: інструкції українською, матеріал англійською). Учень навчається
**вдома самостійно**: кожне пояснення має бути самодостатнім, без «як пояснив учитель» і «відкрий підручник на с.».

## Для кого пишемо: тон за віком

| Клас | Вік | Як писати |
|---|---|---|
| 1–2 | 6–8 | Дуже короткі речення. Інструкції читає дорослий уголос («Дорослий читає: …»). Більше усних завдань (`speak`, `checklist`), мінімум письма. Багато `image` з емодзі та простих `figure`. Урок 20–30 хв. |
| 3–4 | 8–10 | Дружньо, на «ти», без сюсюкання. Приклади з життя дитини. Урок 30–40 хв. |
| 5–6 | 10–12 | Пояснення з прикладами і висновками. Перші справжні означення й правила. Урок 35–40 хв. |
| 7–9 | 12–15 | Предметна мова, означення, доведення, задачі різного рівня. Урок 40–45 хв. |
| 10–11 | 15–17 | Як добрий викладач: точно, без спрощень «для малечі», з причинно-наслідковими зв'язками й роботою з джерелами. Урок 40–45 хв. |

## Каркас файлу

```json
{
  "id": "istu-w05-d4",
  "subject": "istu",
  "title": "Українська Центральна Рада: створення і перші кроки",
  "goal": "Розібратися, як і навіщо у березні 1917 р. постала Українська Центральна Рада і чого вона домагалася.",
  "minutes": 40,
  "terms": {"УЦР": "Українська Центральна Рада", "ТУП": "Товариство українських поступовців"},
  "theory": [ ...блоки теорії... ],
  "exercises": [ ...5–8 вправ, з них ≥3 з автоперевіркою... ],
  "homework": [ ...2–4 завдання: ≥1 з автоперевіркою і ≥1 письмове text... ],
  "reflection": ["Що було найважливішим?", "Де ти помилився і чому?"]
}
```

- `id`, `subject` мають збігатися з `plan.json`; `title` — та сама тема (можна злегка скоротити).
- `minutes` — ціле 10–90.
- `terms` — **усі скорочення уроку** (див. нижче). Необов'язкове `caps` — список слів великими літерами, які НЕ є
  скороченнями (склади й букви в букварі: `["МА","МО"]`); більше ніде не використовуй.

## Скорочення і назви організацій (обов'язково)

1. При **першій згадці** пиши повну назву, а скорочення — в дужках: «Українська Народна Республіка (УНР)»,
   «Організація Об'єднаних Націй (ООН)», «дезоксирибонуклеїнова кислота (ДНК)».
2. Кожне скорочення додай у `terms`: `"УНР": "Українська Народна Республіка"`. Застосунок покаже розшифровку
   при наведенні та окремим блоком «Скорочення».
3. Не пиши звичайні слова великими літерами для наголосу («НЕ», «ЗАВЖДИ») — для цього є `**жирний**`.
4. Римські цифри — **латиницею**: XIX ст., XX ст. (не кирилицею Х, І).
Валідатор ловить нерозшифровані скорочення як помилку.

## Блоки теорії (`theory`)

Порядок довільний, 3–9 блоків. Текст підтримує `**жирний**`, `*курсив*`, перенос рядка `\n`.

| type | поля | призначення |
|---|---|---|
| `p` | `text` | абзац пояснення |
| `rule` | `title`, `text` | правило, означення, «Запам'ятай» |
| `example` | `title`?, `text` | розібраний приклад; у математиці — покроково |
| `list` | `title`?, `items[]` | маркований список |
| `steps` | `title`?, `items[]` | алгоритм дій |
| `table` | `title`?, `head[]`, `rows[][]` | таблиця |
| `reading` | `title`, `author`?, `text`, `genre`? | текст для читання (абзаци через `\n\n`) |
| `vocab` | `title`?, `items[{en, uk, ex?}]` | англійський словник |
| `dialogue` | `title`?, `lines[{who, text}]`, `lang`? | діалог |
| `tip` | `text` | підказка |
| `image` | `emoji`, `caption` | проста «картинка»-емодзі з підписом (1–4 класи) |
| `image` | `src`, `alt`, `caption`, `credit`, `license`, `page` | **справжня ілюстрація** з Wikimedia Commons |
| `figure` | `svg`, `caption`, `alt` | **схема, графік, креслення** — власний SVG |

### Ілюстрації (`image` із Wikimedia Commons)

Обов'язково для історії, літератури (портрети авторів у суспільному надбанні), географії, біології, природознавства:
**1–3 зображення на урок** (портрет, карта, документ, пам'ятка, фото об'єкта). Як додати:

1. Знайди файл на commons.wikimedia.org (WebSearch «site:commons.wikimedia.org …» або WebFetch сторінки категорії).
2. Відкрий сторінку файлу `https://commons.wikimedia.org/wiki/File:…` (WebFetch) і перевір ліцензію:
   **Public domain, CC0, CC BY, CC BY-SA** — так; усе інше — ні.
3. `src` — пряме посилання на зменшену копію шириною 960px: `https://upload.wikimedia.org/wikipedia/commons/thumb/a/ab/Name.jpg/960px-Name.jpg`
   (для SVG-файлів: `.../thumb/.../Name.svg/960px-Name.svg.png`; якщо оригінал вужчий за 960px — посилання на сам оригінал). Мініатюри 640px Wikimedia зараз не віддає (HTTP 400). Посилання бери зі сторінки файлу, не вигадуй.
4. `credit` — автор (як на сторінці файлу), `license` — назва ліцензії, `page` — сторінка файлу, `caption` — що
   зображено і чому це важливо для теми, `alt` — опис для тих, хто не бачить зображення.
5. Перевір `python3 tools/validate.py gXX --net <файл>` — зображення має відкриватися.

### Схеми і графіки (`figure` з власним SVG)

Для математики, геометрії, фізики, хімії, інформатики, а також для хронологічних стрічок, схем держустрою,
кругообігів тощо. Обов'язково там, де без малюнка тему не зрозуміти (геометрична фігура, графік функції, числовий
промінь, схема досліду, електричне коло, будова атома). Правила SVG:

- починається з `<svg` і має `viewBox` (наприклад `viewBox="0 0 320 200"`), без `width/height` або з `width="100%"`;
- лише прості елементи: `line`, `rect`, `circle`, `ellipse`, `polygon`, `polyline`, `path`, `text`, `g`, `marker`/`defs`;
- **заборонено**: `<script>`, обробники `on…=`, `<foreignObject>`, `<image>`, зовнішні посилання;
- кольори: `currentColor` для ліній і тексту, акценти `#2A45B0` (синій), `#D23F58` (червоний), `#1D7449` (зелений),
  заливки прозорі або світлі (`#E4E9F9`); шрифт `font-family="sans-serif"`, розмір тексту 12–16;
- підписи українською; до 12 000 символів; перевір у голові координати — фігура має бути правильною
  (кути, пропорції, точки на графіку відповідають формулі).

Вправа теж може мати `figure` (SVG) або `image` (об'єкт як вище) — показується над умовою (геометрична задача з
кресленням, «що зображено на карті»).

## Вправи (`exercises`) і домашнє (`homework`)

Поле `q` — умова (обов'язкова, крім `truefalse`). Необов'язкові `explain` (після перевірки) і `hint` (після першої помилки).

| type | обов'язкові поля | перевірка |
|---|---|---|
| `choice` | `options[]` (3–5), `answer` (індекс від 0) | один правильний |
| `multi` | `options[]`, `answer[]` | кілька правильних |
| `truefalse` | `items[{text, answer}]` (3–6) | так / ні |
| `fill` | `text` з пропусками `{відповідь}`; варіанти через `\|`: `{п'ять\|5}` | вписати; регістр і пробіли не важливі |
| `number` | `answer` | число (дроби — десятковим записом або через `fill`) |
| `input` | `answer[]` | коротка текстова відповідь |
| `match` | `pairs[[ліво, право]]` (3–6) | з'єднати пари |
| `order` | `items[]` у ПРАВИЛЬНОМУ порядку (3–7) | розставити |
| `sort` | `groups{"Група": [..]}` (2–3) | розкласти |
| `text` | `sample`, `min`? | письмова робота — перевіряють батьки |
| `checklist` | `items[]` | самоперевірка практичної роботи |
| `speak` | `text`, `lang`? | прочитати вголос |

Правила:
1. `exercises`: 5–8 вправ, ≥3 з автоперевіркою. `homework`: 2–4, ≥1 з автоперевіркою і ≥1 `text`
   (1–2 класи: замість `text` можна `checklist` або `speak`).
2. **Кожну відповідь перевір.** Математику порахуй сам (валідатор перевіряє вирази), факти — за двома
   джерелами (дати, імена, назви). Правопис — чинний (2019).
3. Вправи різного рівня: від упізнавання до застосування; у 7–11 класах — задачі з поясненням розв'язку в `explain`.
4. Варіанти без «усі відповіді правильні» і без жартівливих заглушок.
5. Авторське право: не копіюй сучасні тексти. Класику в суспільному надбанні (Шевченко, Франко, Леся Українка,
   Коцюбинський, Нечуй-Левицький, Шекспір, Гюго тощо) можна цитувати; сучасні твори й переклади — переказуй
   своїми словами і цитуй не більше 1–2 рядків. Учень читає повний твір окремо — урок допомагає його зрозуміти.
6. Англійська: словник `vocab` (8–12 слів), хоча б одна вправа `speak`, переклад у відповідях — українською.
7. Розмір файлу — орієнтовно 5–14 КБ (разом із SVG може бути більше).
8. Необов'язкове `extra`: до 3 перевірених посилань для допитливих `[{"title","url","type":"article|video","note"}]`
   лише з надійних джерел (uk.wikipedia.org, esu.com.ua, mon.gov.ua, музеї, офіційні канали). Кожне відкрий WebFetch.
